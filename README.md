## Publish with GitHub Pages

1. Open the repository's **Settings** tab on GitHub.
2. Open **Pages** under **Code and automation**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select the `main` branch and the `/(root)` folder, then save.
5. Wait for GitHub Pages to finish its first deployment. GitHub will show the published site URL in Settings → Pages.
6. Open the published `ldr-vs-photodiode.html` page and test it on desktop and mobile.
7. Only submit the final live URL to search engines after checking that the page loads correctly and the canonical URL (if later added) matches the actual deployed address.

**Note:** Committing an HTML file does not itself enable GitHub Pages. Pages hosting must be enabled in repository settings by an account with the required permissions.
